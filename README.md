# Ubuntu Toolbox

Skrip utilitas ringan untuk membersihkan RAM dan sampah sistem di Ubuntu melalui Terminal.

## Fitur Utama
- **Cleaner & Memory:** Clear RAM Cache, Reset Swap, Auto-Clear RAM (tiap 30 menit), dan pembersih sampah APT/Journal.
- **Utilitas:** Tes ping koneksi internet.

## Cara Instalasi
```bash
git clone https://github.com/aryasatyan666/ubuntu-toolbox
cd ubuntu-toolbox
bash install.sh
```

## Cara Penggunaan
Buka Terminal dan jalankan perintah:
```bash
toolbox
```
